# Saved reports

Keep the before/after evidence for the write-up here. From a pipeline run, download the
`security-report` artifact and copy `security-report.md` and `security-report.json` into:

- `before/` – the first run on unmodified NodeGoat (gate fails)
- `after/` – the first run where the gate passes

Also save screenshots of both runs (the Actions run page and its summary) next to the reports.
